# Mood music beds

One folder per mood, used by `history` (`--music-mood`), `poll`, and `montage`
(`--mood`). Royalty-free tracks only — commercial songs will get flagged/muted.
For trending commercial sounds (e.g. Taylor Swift), render with
`montage --no-music` and attach the sound inside TikTok when posting.

```
assets/music/moods/sad/rainy_piano.mp3
assets/music/moods/cinematic/epic_strings.mp3
assets/music/moods/suspense/ticking.mp3
```
