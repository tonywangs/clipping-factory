# B-roll collections

One folder per scenery collection used by `montage` (and any format that wants
b-roll). Only add footage you have rights to (your own recordings, licensed
stock, CC0).

```
assets/broll/nyc-rain/street_night.mp4
assets/broll/nyc-rain/window_drops.mp4
```

```bash
python -m clipfactory.create montage --collection nyc-rain --mood sad
```
